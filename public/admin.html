天气组件

天气与日历是首页的两个小组件，可在首页直接拖动，与标签混排。
Open-Meteo：无需注册、无需密钥，按经纬度取数；国内网络不稳时会自动回退到中国天气网。
中国天气网（免登录免密钥）：直接调用 weather.com.cn 的公开数据，按城市名查城市码，返回实时温度与 5 天预报。不需要账号、不需要 Key，选中保存即可用。
和风天气新版 JWT 操作步骤（旧版 API KEY 已移除）
  1. 登录 和风天气控制台 → 项目管理 → 创建项目（免费订阅即可），记下 项目 ID（形如 QWP123456）。
  2. 在该项目下点 凭据 → 添加凭据，认证方式选 JSON Web Token (JWT)。
  3. 在下方点「生成密钥对」，OnlyTab 会把 私钥自动保存在服务端，并展示 公钥；把公钥完整粘贴到第 2 步的控制台里保存。
  4. 回到控制台凭据列表，复制 凭据 ID（形如 QWT123456），填入下方「凭据 ID」；项目 ID 填入「项目 ID」。
  5. 点页面底部「保存」。之后 OnlyTab 会用 Ed25519 签名生成 JWT，通过 Authorization: Bearer 调用和风接口。私钥永不下发到浏览器。
提示：JWT 未配置完整时会自动回退到中国天气网，天气不会空白。

布局与排序

首页的天气、日历与所有标签在同一个面板里，可直接拖动混排：鼠标按住拖动，手机长按后拖动。排序会保存到服务端，所有设备同步。
